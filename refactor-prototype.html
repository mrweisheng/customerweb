客资管理 · 重构原型
Refactor Spec v2.0
3 个页面 · 1 个录入入口 · 1 个编辑面板
Information Architecture

总览：7 页收敛为 3 页 + 2 独立流程

重构原则：一个功能只有一个入口——数字只在统计页出现，录入只有一个入口，所有客户编辑都通过唯一的详情面板完成。菜单即功能，不再重复。

现状 · 7 个页面

4 Tab + 3 隐藏页，5 组功能重复实现
🏠首页 Home拆分KPI/趋势/日历 → 统计；内嵌导入 → 导入流程；问候/每日一句 → 删除
⭐重点 Priority升级升级为「工作台」，吸收搜索与录入入口
📊统计 Statistics精简删除重点客户卡 / 按日期明细 / 重复趋势图
👤我的 Mine精简删除 3 个「敬请期待」死菜单
🔍搜索 Search合并与重点页内嵌搜索完全重复，整页删除
🤖AI 导入 AiImport合并与首页内嵌导入调同一组 API，两套实现合一
🔑登录 Login保留删繁体文案 / 1 秒延迟跳转 / 营销特性
→

重构后 · 3 Tab + 2 独立流程

菜单即功能，一一对应，零重复
🗂工作台（Tab 1）日常主阵地搜索 + 重点客户列表 + 筛选 + 唯一「录入」入口
📈统计（Tab 2）只读聚合KPI / 趋势 / 成交统计 / 成交到店明细，全系统数字只在此出现
👤我的（Tab 3）账号头像昵称 + 数据范围（管理员）+ 退出
🤖导入流程（全屏）唯一录入三步：选图 → 确认 → 结果；支持点击 / 拖拽 / Ctrl+V 粘贴
✏️客户编辑面板（组件）唯一编辑需求 / 跟进 / 到店登记 / 成交 / 标注重点，五件事一个面板
🔑登录（独立页）唯一门槛未登录一律跳转，删除各页假数据模式
旧页面 / 区块去向动作
Search.vue 整页并入工作台顶部搜索框；本地搜索历史一并迁入删除
AiImport.vue + Home 内嵌导入合并为唯一「导入」全屏流程（统一组件 ImportFlow）合并
Home.vue KPI / 趋势图 / 更新日历迁入统计页（原本与统计页双实现）迁移
Home.vue 问候语 / 每日一句 / 死代码弹窗直接移除（设置重点弹窗本就无入口，永不可达）删除
Priority.vue 月度成交/到店面板并入统计页「成交 / 到店明细」（可切月）迁移
Statistics.vue 重点客户卡 / 按日期明细重点列表归工作台；按日期明细为低频入口，搜索可覆盖删除
管理员「切换用户」×3 处复制收口：PC 侧栏 + 我的页各一处（共享全局状态）收口
Mine.vue 三个「敬请期待」菜单直接移除，退出登录去掉二次确认删除
未登录假数据（mock）×4 处删除，路由守卫统一跳转登录页删除

原进入详情的 5 类入口（搜索结果 / 重点卡 / 统计重点列表 / 日期明细 / 首页）收敛为 2 类：工作台列表与搜索结果。PC 端由居中弹窗改为右侧抽屉，列表上下文不丢失。
2
「当前需求」独立为客户级字段 新增
修复原设计：需求挂在到店记录的 needs 字段上，更新需求必须重走到店表单。改为客户表 current_needs 字段（后端小迁移 + PUT 接口），面板顶部常显，随时可见可改。
3
「更新需求」一键完成 新增
重点跟进时最常更新的就是需求：点「更新需求」→ 改文字 / 点快捷标签 → 保存。保存同时可选在跟进时间线自动留痕。
4
跟进输入框语义单一化 删除
原输入框身兼三职（客户需求 / 重点备注 / 跟进内容），按钮时隐时现、路径反直觉。现在它只做一件事：记录跟进，且始终可写可提交。
5
到店登记保留自动标重点 保留
「登记到店 → 自动标为重点」的后端行为保留；表单仍是时间 / 需求 / 备注，需求默认带入当前需求字段。
6
成交表单保留车辆 / 两地牌双 Tab 保留
添加成交后自动移出重点列表（现有行为）；表单结构不变（车架号 / 口岸 / 期现牌等），仅纳入新面板视觉规范。
7
重点开关固定在底部 保留
「标注重点 / 取消重点」保留互斥按钮；删除首页那套永不可达的「设置重点弹窗」死代码（约 80 行）。
